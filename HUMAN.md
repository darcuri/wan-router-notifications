## Why the [HUMAN.md] file?

### AI Influence

Most everything else in this project wasn’t done in a code IDE, it was done in a Claude Code conversation. More as a proof of concept of “vibe” (sigh) coding from the perspective of a senior engineer who’s ~~written~~ hacked on bad code for years and now has a tool to clean up and/or write its own code. But this? This file is mine. Typed in by hand without even any AI suggestions.

### People matter too

When AI writes everything, where are our own voices? I don’t want us to get **too** lazy(-er?) because that’ll be the end of ingenuity. Innovation through pure human ideation. It’s how we got the tools to begin with. There’s math and science sure but also a motivation driving it that was purely grey matter. Let’s hang on to that, ok?

Like many other people I found the tools useful if you could guide them and even more useful if you already knew how to do what you wanted to do, you were just too lazy to do it. (I’m talking about myself, yes.)
