# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it using
[GitHub's private security advisory feature](https://github.com/darcuri/wan-router-notifications/security/advisories/new).

**Do not** open a public issue for security vulnerabilities.

## Scope

This policy covers the wan-router-notifications software itself. It does not
cover any specific deployment, infrastructure, or network environment where the
software may be running.

Examples of security issues in scope:

- Credential or secret exposure in code or logs
- Injection vulnerabilities (command, code, or query injection)
- Unauthorized access to monitoring endpoints
- Dependency vulnerabilities that affect this project

## Response

This is a personal project maintained on a best-effort basis. I will acknowledge
reports as promptly as I can and work to address confirmed vulnerabilities in a
timely manner.
